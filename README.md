# Hudi Orb Generator

A focused Next.js version of the ticker orb generator from
[4madeo/Hudi-style-sheet](https://github.com/4madeo/Hudi-style-sheet).

It includes the original four sizing options (240px, 120px, 43.2px, and
21.6px), ticker and number editing, palette presets, material-token controls,
and CSS copying.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

The repository is compatible with Vercel's standard Next.js deployment flow.
